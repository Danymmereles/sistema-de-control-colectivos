# Sistema de Control de Colectivos

Aplicación React + Vite completamente estática para simular el control de colectivos.

## Requisitos

- Node.js 20 o superior

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación y build

```bash
npm run lint
npm run build
```

El build se genera en `dist/`. Está configurado para GitHub Pages en la ruta
`/sistema-de-control-colectivos/` y se publica mediante el workflow de GitHub Actions.
